# David v2 Data Provenance Matrix

This matrix covers the planned David `/credit/v2` surface against the current governed backend contract.

Rules:

- Every visible business field must come from `GET /credit/v2` or a later approved backend/API extension.
- Decision-like fields must carry backend `recordIds` plus backend deterministic basis, or render `Contract gap`.
- Aggregate KPI rows may use `n/a - aggregate summary` for `Record IDs` and `Deterministic basis` when they are not decision-like.
- UI-only flow state such as search text, selected account, active section, and walkthrough-strip progress is intentionally omitted here because it is not business truth.

Current contract gaps that must stay honest in UI:

1. Mesh tiles are covered: `accounts[].meshPositions[]` already carries `recordIds`, `deterministicBasis`, and `contractGap` fallback.
